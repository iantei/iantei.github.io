Realtime Audio Lab Swift · C++ · vDSP
github.com/iantei/swiftui-realtime-audio

A tone generator and live spectrum analyser built around a lock-free single-producer/single-consumer ring buffer with acquire/release atomics and wait-free atomic parameter passing, so the CoreAudio render thread never allocates, locks, or awaits under a ~5.3 ms deadline (48 kHz / 256-frame buffer). Windowed real FFT via Accelerate/vDSP; PolyBLEP band-limited oscillators; Swift 6 strict concurrency with an actor-owned engine and AsyncStream frame delivery. ~1,180 lines, with tests covering ring-buffer wrap-around and torn reads, oscillator phase continuity, and analyser calibration.

Builds and runs as a macOS host app; the UI is platform-agnostic and iOS-ready but has not been run on an iOS device or Simulator.

lock-free · atomics · memory ordering · real-time DSP
